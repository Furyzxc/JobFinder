# Nexus

A social networking app where users can connect with friends, browse a live news feed, and discover new people. Nexus was my first full-scale React project — built while learning React fundamentals, API integration, and modern frontend development practices from scratch.

🔗 **Live demo:** [jobfinder-social-network.netlify.app](https://jobfinder-social-network.netlify.app)

## About

This project was where I taught myself:
- Component architecture and reusable UI patterns
- State management with Redux Toolkit
- API integration and asynchronous data handling
- Proper project file structure
- Git version control and deployment workflows

## Features

- Connect with other users
- Profile editing
- Live news feed
- Discover/browse new people
- Settings page

## Tech Stack

- **Frontend:** React, Redux Toolkit
- **Styling:** Material UI
- **API:** (https://social-network.samuraijs.com/)
- **Deployment:** Netlify

## Getting Started

### Prerequisites
- Node.js and npm installed

### Installation

```bash
git clone https://github.com/Furyzxc/JobFinder.git
cd JobFinder
npm install
npm start
```

The app will run at `http://localhost:5173`.
